# 🎬 한국어 더빙 연습 스튜디오

말로 설명해 주신 아이디어를 그대로 만든 **한국어 수업용 더빙 연습 웹앱 프로토타입**이에요.

> “동영상에 녹음하는 어플. AI로 상황을 동영상으로 만들어. 그다음에 배경음과 효과음은 그대로인데, 대사만 묵음이야. 거기에 학생이 직접 녹음하는 거지.”

## 파일
| 파일 | 설명 |
|---|---|
| `korean-dubbing-studio.html` | 앱 본체. CSS·JS·그림 3장이 모두 안에 들어 있어 **파일 하나로** 열려요 (약 0.58MB). |
| `scene1.png` · `scene2.png` · `scene3.png` | 앱에 들어간 카페 장면 원본 그림 (16:9). |

## 이렇게 동작해요
1. **▶︎ 샘플 재생** — 20초짜리 “☕ 서울 카페에서 주문하기” 장면이 흐릅니다.
   - 장면 3개를 천천히 확대·이동(켄 번즈)하며 넘어가요.
   - 배경음은 앱이 직접 만듭니다: 카페 소음 + 잔잔한 로파이 코드 + 문 종소리(0초) + 에스프레소 스팀·컵 소리(16초). **대사만 비어 있어요.**
   - 직원 대사는 한국어 TTS로 들려주고(켜고 끌 수 있어요), 자막이 함께 떠요.
2. **🎙️ 녹음 시작** — 3초 카운트다운 뒤 영상이 처음부터 흐르고, 내 차례에 **“🎙️ 지금 말하세요!”** 표시와 진행 막대가 나타납니다. 배경음은 계속 흐르고 내 목소리만 녹음돼요.
   - 5개 턴: 직원 3 / 학생 2 (3.5–8.5초, 12.0–16.5초)
3. **🎧 합본 다시듣기** — 장면 + 배경음 + 내 목소리를 함께 재생. `배경음`·`내 목소리` 슬라이더로 균형을 맞춰요.
4. **📁 내 영상 불러오기** — AI로 만든 내 영상(mp4·mov·webm)을 올리면 그 영상 위에 자유롭게 더빙할 수 있어요. 영상의 원래 소리는 배경음으로 재생됩니다.
5. **💾 저장하기**
   - 내 목소리만 (WAV)
   - 합본 오디오 (WAV) — 배경음 + 내 목소리
   - 합본 영상 (webm, 데스크톱 크롬만) — 화면과 소리를 실시간으로 녹화

## 여는 방법
- **데스크톱(크롬·엣지·사파리)**: 파일을 더블클릭하면 바로 열려요. 마이크 권한을 허용하면 녹음까지 됩니다.
- **아이폰**: 파일을 ‘파일’ 앱에 넣고 열면 화면은 보이지만, **마이크 녹음은 https 주소에서만** 허용돼요(사파리 보안 규칙). 실제 수업에 쓰려면 이 파일을 GitHub Pages·Netlify Drop 같은 무료 정적 호스팅에 올려 https 주소로 여는 것을 권해요.

## 알아둘 점
- 아이폰 사파리는 화면 영상 저장(Canvas capture)을 지원하지 않아요 → ‘합본 영상 저장’ 버튼이 잠깁니다. 대신 WAV로 저장하거나 데스크톱 크롬에서 저장하세요.
- 녹음은 마이크만 담깁니다. 배경음이 스피커로 나오면 함께 섞일 수 있으니 **이어폰**을 끼면 내 목소리만 깔끔하게 담겨요.
- TTS 목소리는 기기에 설치된 한국어 음성을 씁니다(아이폰: 설정 → 손쉬운 사용 → 콘텐츠 말하기에서 음성 추가 가능).
- 인터넷 없이도 열립니다. 외부 라이브러리를 쓰지 않았어요.
